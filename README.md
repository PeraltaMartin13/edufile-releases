# EduFile — instaladores

EduFile es un programa gratuito para Windows que ordena los datos de alumnos, familias y docentes
de las secretarías de las escuelas, con planillas, pase de año y sincronización entre las PCs.

**[Descargar la última versión](https://github.com/PeraltaMartin13/edufile-releases/releases/latest/download/edufile-instalador.exe)**
· [Página de EduFile](https://edufile-landing.vercel.app)

Este repositorio tiene solo los instaladores (en *Releases*); el código del programa es privado.
El programa instalado busca acá las versiones nuevas, las descarga solo y las instala al cerrarse.

- Windows 10 y 11, 64 bits.
- Si Windows muestra "Windows protegió su PC", es porque el instalador todavía no tiene firma
  digital: tocá "Más información" y después "Ejecutar de todas formas".
- Instalar una versión nueva encima conserva los datos.
